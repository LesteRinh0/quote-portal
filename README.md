# Quote & Client Portal

Quote & Client Portal помогает быстро собрать смету, показать клиенту состав работ и согласовать стоимость. Вместо документа, который приходится пересылать после каждого изменения, здесь можно менять позиции, сразу видеть итог и открыть смету в виде клиентской страницы.

Приложение подойдёт фрилансеру, небольшой студии, менеджеру проектов или мастеру, который хочет вести предложения и контакты клиентов в одном месте.

## Первый запуск

При первом открытии уже загружены демо-профиль студии, четыре клиента, каталог типовых услуг и три сметы в разных статусах. Можно сразу открыть дашборд, посмотреть расчёты и пройти путь по разделам, ничего предварительно не настраивая.

Сметы, клиенты и шаблоны хранятся в локальном хранилище браузера. Данные остаются на этом устройстве и в этом браузере.

> **Ограничение демо-версии:** сейчас у приложения нет общей серверной базы. Ссылка `/p/:slug` открывает портал в том браузере, где есть эта смета. Если отправить её человеку на другом устройстве, его браузер не получит ваши локальные данные. Для настоящей совместной работы с клиентами понадобится подключить общее серверное или облачное хранилище.

## Как подготовить смету

### 1. Создайте предложение

Откройте **«Новая смета»**. Укажите название, выберите клиента, валюту, статус и срок действия. Если клиента ещё нет, нажмите **«+»** рядом со списком и добавьте его, не закрывая редактор.

Состав сметы можно подготовить тремя способами:

- **Вручную:** добавьте раздел, например «Подготовка» или «Разработка», затем добавьте позиции и заполните название, описание, единицу измерения, количество и цену.
- **Из каталога:** внизу раздела выберите услугу из справочника. Название, описание, единица и цена перенесутся в смету; значения можно сразу поправить.
- **Из брифа:** нажмите **«Сгенерировать из брифа»** и вставьте описание проекта или нужный фрагмент переписки. Генератор работает прямо в браузере, распознаёт темы вроде дизайна, разработки, интеграций, SEO и поддержки, а затем добавляет подходящие черновые разделы. Цены и состав проверьте перед отправкой.

### 2. Настройте позиции, скидку и оплату

Каждая позиция может быть:

- **Обязательной** — входит в смету всегда.
- **Опцией** — клиент может включить или отключить её галочкой.
- **Выбором варианта** — клиент выбирает один тариф, например базовый, оптимальный или расширенный. Для каждого варианта задаются название и цена.

В разделе **«Скидка и оплата»** выберите процентную или фиксированную скидку и добавьте этапы оплаты. Для этапа укажите название, процент, срок или условие и отметьте оплату, если она уже поступила. Индикатор покажет, если проценты этапов в сумме отличаются от 100%.

Справа редактор показывает живой предпросмотр: выбранные позиции, скидку, итог и суммы этапов. При изменении количества, варианта или опции расчёт обновляется сразу.

### 3. Откройте клиентский портал

Сначала сохраните смету, затем нажмите **«Скопировать ссылку клиента»**. Ссылка ведёт на `/p/:slug`. В портале клиент видит состав работ, текущую стоимость, этапы оплаты и срок действия предложения. Он может выбирать варианты и включать опции — итог пересчитывается на странице.

В портале есть лента комментариев и кнопка **«Согласовать смету»**. При согласовании клиент вводит имя; статус предложения меняется, а событие добавляется в журнал. После согласования выбранные опции и тариф фиксируются. Кнопка **«Скачать / Распечатать PDF»** открывает диалог печати браузера — там можно выбрать сохранение в PDF.

Если отправленная смета открывается в портале впервые, её статус меняется с **«Отправлена»** на **«Просмотрена»**, и в журнал добавляется событие просмотра.

### 4. Ведите справочники и сохраняйте данные

В разделе **«Клиенты»** добавляйте и редактируйте контакты, смотрите связанные с ними сметы и согласованную сумму. В **«Услугах и шаблонах»** поддерживайте каталог типовых работ, чтобы быстрее собирать новые предложения.

Кнопки в верхней панели помогают управлять локальной базой:

- **Экспорт JSON** скачивает резервную копию клиентов, шаблонов, профиля и смет.
- **Импорт JSON** загружает ранее сохранённую копию и проверяет её структуру. Если файл повреждён, приложение покажет понятную ошибку.
- **Сброс демо** возвращает исходные примеры и удаляет текущие изменения из локального хранилища этого браузера. Перед сбросом сохраните экспорт, если хотите оставить копию.

Периодически скачивайте экспорт JSON: очистка данных браузера или переход на другое устройство не переносит локальную базу автоматически.

## Для запуска локально и деплоя

Нужен Node.js 22 или совместимая актуальная версия.

```bash
npm install
npm run dev
```

Для production-сборки и локального просмотра результата:

```bash
npm run build
npm run preview
```

Чтобы опубликовать приложение на Vercel, импортируйте репозиторий в Vercel и оставьте настройки сборки для Vite по умолчанию: команда сборки `npm run build`, папка результата `dist`. В корне уже есть `vercel.json` с SPA-переадресацией на `index.html`, поэтому прямые ссылки вроде `/p/teply-bereg-site` загрузят приложение.

Перед публикацией можно выполнить полную проверку:

```bash
npx tsc --noEmit
npm test
npm run build
```
